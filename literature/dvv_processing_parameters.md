# dv/v passive-monitoring processing parameters by application

Literature-derived processing parameters for ambient-noise / coda seismic velocity-change (dv/v) monitoring, organized by science application. **103 unique studies.** Every row links to a verified DOI; `n/r` = not reported in the source (not guessed).

The machine-readable version with all columns is [dvv_processing_parameters.csv](dvv_processing_parameters.csv); consolidated best-practice rules are in [best_practices.md](best_practices.md); column definitions and methodology are in [README.md](README.md).
